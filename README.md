# SJA — فروٹ سبزی کھاتہ

شیخ جاوید شیخ عاطف کمیشن شاپ (سبزی منڈی جی ٹی روڈ کامونکے) کا بل اور کھاتہ سسٹم۔

- **نیا بل** — پارٹی، اشیاء، مارکہ، دانہ، نگ، ریٹ؛ بل پرنٹ (A5 / A4)
- **وصولی** — جمع رقم کی رسید
- **کھاتہ** — پارٹی کا مکمل حساب (بل نمبر، تاریخ، نام رقم، جمع رقم، بقایا)
- **رپورٹ** — روزنامچہ، بقایا لسٹ
- انٹرنیٹ کے بغیر بھی چلتا ہے (فونٹس اور ایپ کی فائلیں ساتھ ہیں)

ایپ `docs/` فولڈر میں ہے۔ کمپیوٹر پر کھولنے کے لیے `Start SJA.bat`۔

ابھی ڈیٹا اسی براؤزر میں محفوظ ہوتا ہے (`docs/js/firebase-config.js` میں `null`)۔ ہر ہفتے "سیٹنگ ← بیک اپ ڈاؤن لوڈ" ضرور کریں۔
